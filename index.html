This site hosts Packwiz metadata and approved client artifacts.

Download The Gangs Modpack v1.1.2 (All-in-One)

Import this ZIP through Prism Launcher with Add Instance then Import. Mods are bundled. Use Java 17 or newer; internet access is required for automatic update checks.

Keep the same Prism instance and press Play for future updates. Existing players should run the included client-update installer once against their existing instance. Saved keybindings, options and server lists are preserved; do not import a new instance for every update.
