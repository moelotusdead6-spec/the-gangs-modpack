The Gangs Modpack v1.1.5 - server update

STOP THE SERVER and keep a world backup before applying this update.
Run PowerShell:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-ServerUpdate.ps1 -GameDirectory "C:\path\to\server"

The installer backs up touched files and installs GoldClaim 1.0.33,
removes YUNG's Better End Island and routes the retained True Ending
dragon overhaul to RSW End. Good Ending (Overworld content) is unchanged.
To replace an existing YUNG arena with a clean End, append -ResetRswEnd.
This MOVES only the RSW End dimension into the update backup, including
its dragon fight state, so it regenerates on startup. Without that flag,
all world folders are preserved. Keep a full world backup separately.
Update-file backups retain three generations, pruning the oldest before
creating the new backup. Other backup categories are not pruned.
removes JEI, installs server-applicable mods (EndsPhantasm, Nullscape,
Shield Overhaul, Necronomicon, Immersive Armors, Roughly Enough Items,
bc_particle), and retains view-distance=6 / simulation-distance=6.
RSW rotation now includes Overworld, Nether (with 1:1 coordinate scaling
to protect players within the 5,000-block radius border), and The End.
Portals in the wild Overworld can be lit but cannot be entered.
Blood Moons are moved exclusively to RSW. /rtp is restricted to Wild
Overworld and RSW Overworld. Other settings, worlds, player data, claims,
homes, kit data and the RSW reset journal are preserved. The installer
DOES NOT start the server.

v1.1.5 adds Supplementaries, Supplementaries Squared, Ender Zoology,
Better End Cities for Better End, BetterEnd, BCLib, Elytra Slot, and
Macaw's Doors, Windows, Furniture, Roofs and Trapdoors. Existing required
Moonlight, Puzzles Lib, Forge Config API Port, Trinkets and Fabric API stay.
Gang Shop 1.0.9 puts all Macaw's items in one Macaw's category without
replacing prices, category settings or wallet data.
GoldClaim bans Waystones blocks, item use and travel in all three RSW worlds.
On next startup, existing Wild waystones never activated by ANY player are
removed without drops; offline players' activations are included. Activated
Wild stones are preserved. This is a one-time cleanup, not deletion of future
Wild placements. Original region/waystone files and the cleanup plan are kept
under backups\waystones-policy-v1.1.5\<level-name>, outside world generation.
Cleanup saves changed chunks and registry before marking itself complete.
Do NOT repeat -ResetRswEnd for the server already prepared with v1.1.4.

Do not overwrite live configs with the full config folder: it is supplied
for new installations/reference. The installer merges only this update's
policy changes. Keep other custom mod settings.
For a server without start.bat, update any launcher jar-version pins manually.
Keep only one GoldClaim jar installed.
Keep only one Gangs Cosmetics jar installed; remove every Gangs Hats jar.

Players can attack vanilla and modded hostile mobs in claims without trust.
This uses Minecraft's Monster interface or MONSTER spawn group, not a mob
name allowlist. Tamed pets stay protected, including modded monster-category
pets. Animals, villagers, decorations, inventory access, entity interaction
and block protections remain unchanged.

/trash is available to all players as a native 27-slot disposable container.
Place unwanted items in the bin and close it to dispose of them permanently.
It does not depend on Essential Commands' /wastebin registration or settings.

Inception upgrades cannot be crafted or acquired, including commands, loot
and creative packets. Existing upgrades load empty, including installed
upgrade slots. Other upgrades, backpack items, child-backpack items and
stored contents are preserved; disabled nesting no longer exposes child
inventories through the parent backpack. Remove child backpacks beforehand
if you want immediate access to their contents after the update.

Only sarosplayerplushiemod:plushie has its crafting recipe restored.
All other plushie/plush-box recipes remain disabled.
/rsw fire spread is disabled when its dimension loads, after each daily/manual
reset, and during world maintenance. This also disables natural fire burnout;
existing fires are not removed and other fire damage is not disabled.
First-entry safety and exact saved return positions remain unchanged.

Clients: close Minecraft and run client-update\Install-ClientUpdate.ps1
against the actual Prism game root once to enable automatic client-only updates.
Options, keybindings, resource-pack choices and servers.dat are preserved.
After setup, keep that instance and press Play; do not import a new instance
for every release. Default Options supplies missing first-run defaults only.
Do not copy the entire client mods folder to the server.

Start the server yourself. Check Saro crafting, rejected Inception /give and
crafting, loaded backpack upgrades/contents, other plushie recipes, and RSW
first-entry/return behavior in-game before discarding backups. Verify that
untrusted visitors can fight hostile mobs but cannot hit pets or animals,
open claim inventories or break claim blocks.
