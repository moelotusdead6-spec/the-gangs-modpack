# v1.1.11: Claim borders on the JourneyMap full-screen map

## Same instance, same update workflow

Keep your existing Prism instance and press **Play**. The pre-launch command
is unchanged and runs Packwiz with `-g -s client`. The public all-in-one ZIP
is for **new installs**, not a required reimport for existing players.

Clients download one new mod, **GoldClaim Map 1.0.0** (`side = "client"`).
No client configs change. Personal `options.txt` (keybindings and
resource-pack selections), `optionsof.txt`, `optionsshaders.txt`,
`servers.dat`, `servers.dat_old` and Default Options journals remain excluded
from updates.

## What's new

Open JourneyMap's full-screen map to see every claim on the server:

- Each claim is drawn as its exact block rectangle: a soft gold outline over a
  faint amber fill. It is kept translucent so it does not cover the terrain.
- Hover over a claim to see its owner's name, or **Server claim** for admin
  claims. The label is semi-transparent and disappears when you move away.
- Borders are **not** drawn on the minimap.
- The map updates as claims are created, expanded or removed.

## How it works

- **GoldClaim 1.0.42 (server only)** sends claim rectangles, the dimension,
  the owner's name and the admin flag on the `goldclaim:claim_map` channel.
  It sends nothing else from the claim (no trust lists or UUIDs).
- It sends only to clients that have GoldClaim Map. A player receives the full
  list when their client registers the channel, and everyone with the mod
  receives it again after a claim change, at most once per server tick.
- **GoldClaim Map 1.0.0 (client only)** is a separate mod and needs
  JourneyMap, which the pack already includes. It contains no GoldClaim server
  code, so single-player and LAN worlds are unaffected. With no GoldClaim
  server, it simply shows no claims.
- Either side can update first. A 1.0.42 server sends nothing to clients
  without the mod, and the mod shows nothing on a 1.0.41 server.

Claim protection, claim limits and all other GoldClaim 1.0.41 behaviour are
unchanged.

## Server deployment

Nothing is deployed by publishing. Choose one path:

- **Next normal restart (running server untouched):** stage with
  `scripts\Stage-GameplayHotfix.ps1 -GameDirectory '<server>' -Version 1.0.42`.
  On the next start, the existing launcher hook verifies the checksums. It
  backs up GoldClaim 1.0.41 to `mod-backups/gameplay-1.0.42`, then installs
  1.0.42. Rollback: restore that jar, remove 1.0.42 and restore
  `start.bat.bak_before_goldclaim_1.0.42`.
- **Stopped-server payload:** the v1.1.11 ZIP's `server-update` installs
  checksum-pinned GoldClaim 1.0.42 and updates the launcher pin.

Do not put GoldClaim Map on the server. It is client-only and Fabric skips it
on a dedicated server.
