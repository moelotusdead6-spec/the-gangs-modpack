# v1.1.13 - leftover JEI cleanup and pending restart bundle

- The manual client installer now backs up and removes JEI jars, including
  `.jar.pending` files, instead of leaving JEI active alongside REI.
- Normal auto-updating Prism clients can keep the same instance and press Play.
  Previously managed JEI is removed by Packwiz; clients that already have only
  REI need no cleanup. No elevator behavior change is included in this release.
- Existing auto-updating clients can run the included
  `client-update/Remove-ClientJei.ps1` once with Minecraft and Prism closed.
  Supply the existing game directory using `-GameDirectory`. This standalone
  cleanup preserves REI, other mods, launcher configuration and personal settings.
  Packwiz can remove previously managed files, but cannot be relied on to remove
  old, unmanaged JEI jars. A server restart cannot change client installations.
- New-install ZIPs continue to exclude JEI and retain REI 12.1.785.
- The server payload now includes the already-pending GoldClaim 1.0.43
  grave-recovery and teleport tick-stall hotfix, not 1.0.42. Previous kit,
  Lootr, claim-map and future-reset fixes remain included.

## Elevator investigation

The live server and pack both use OpenBlocks Elevator 0.0.3 for Fabric 1.20.1.
Its actual configuration is `config/openblocksconfig.properties`, with only
`openblocks.elevator.block.range` (currently 20). It does **not** read a
`centerPlayerOnTeleport` setting.

Inspection of the installed jar's `ElevatorBlockFunctions.goUp` and `goDown`
confirms that both already call teleport with the elevator block's X + 0.5,
destination Y + 1, and Z + 0.5. No speculative elevator patch or ignored
configuration property is shipped. This verifies the intended coordinates,
not the reported in-game symptom: the centering issue remains unconfirmed
and still needs an in-game reproduction before a safe behavioral fix.
