# The Gangs Modpack v1.1.4

## End dragon compatibility

- Removed YUNG's Better End Island from Packwiz and all public ZIP mod payloads.
  Other YUNG mods and YUNG's API remain.
- Retained **True Ending: Ender Dragon Overhaul 1.1.0c**, by **limesplatus**.
  [Official project](https://modrinth.com/mod/true-ending).
  Good Ending 1.1.0 is unrelated Overworld content and is unchanged.
- Removed GoldClaim's Better End Island reflection, bell tick, extra saved flags,
  and manual initial-respawn calls. Minecraft ticks the RSW End dragon fight
  normally; GoldClaim still initializes it and persists its data separately from
  the vanilla End.
- Added pack-managed compatibility resources under `gangs_fixes` to execute
  True Ending's tick once per server tick in `multiworld:rsw_the_end`, including
  its dimension-specific music, predicates, entry advancement, XP, respawn
  animation, and exit-portal effects. The original True Ending jar is unchanged.
  Global clocks are not ticked a second time.
- Regenerate these overrides with `scripts/Build-TrueEndingRswCompatibility.ps1`
  using the official hash-verified True Ending jar. These are minor compatibility
  edits permitted by the author's [license](https://github.com/SpluoSplatus/Vanilla-Refresh/wiki/License),
  sections A4, B2 and C1/C2. Upstream authorship is retained.

## Installation and preservation

Existing clients keep their Prism instance and press Play. The client-only
Packwiz hook removes the managed Better End Island mod; it never replaces
personal options, keybindings, resource-pack selections, server lists or
Default Options journals. The new public ZIP is only for new installations.

The separate server installer requires a stopped server, backs up changed
files, and never starts it. It removes Better End Island and installs the new
GoldClaim artifact and compatibility datapack. It retains three update-file
backup generations, pruning the oldest first; unrelated backups are untouched.

For a clean fight after removing an existing YUNG arena, explicitly use
`-ResetRswEnd`. This archives only the RSW End folder (terrain, entities and fight
state) into that update's backup before regeneration. It does not delete Wild,
RSW Overworld, RSW Nether, claims, player data or the RSW reset journal.
Back up the full world separately before applying. The owner approved this
End-only regeneration for the local stopped server.

Portal restrictions, 1:1 Nether travel, synchronized daily resets, borders,
Blood Moon scope and `/rtp` restrictions are unchanged.
