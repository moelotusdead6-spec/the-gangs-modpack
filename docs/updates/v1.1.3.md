# The Gangs Modpack v1.1.3

- Replaced Just Enough Items (JEI) entirely with Roughly Enough Items (REI) 12.1.785.
  JEI-specific keybindings purged from default options and active options; REI keybindings
  configured cleanly.
- Added 7 new mods:
  - Roughly Enough Items (REI) 12.1.785
  - End's Phantasm 1.4
  - Nullscape 1.2.8
  - Shield Overhaul 2.0.4
  - Necronomicon 1.6.0+1.20.1
  - Immersive Armors 1.7.2+1.20.1
  - Better Combat Particles (bc_particle) 0.0.6
- Resetting World (RSW) expanded to a 3-dimension rotation:
  - `multiworld:rsw` (Overworld)
  - `multiworld:rsw_nether` (Nether)
  - `multiworld:rsw_the_end` (The End)
- All 3 RSW dimensions reset together with matching seeds and have 10,000-block diameter
  (5,000-block radius) world borders centered at (0, 0).
- RSW Nether uses a custom dimension type (`gangs:rsw_nether`) with `coordinate_scale: 1.0`
  (Option C). This provides 1:1 coordinate scaling with the RSW Overworld so exiting Nether
  portals never scales coordinates 8x and never places players beyond the 5,000-block border.
- Nether and End portals in the wild Overworld can be lit normally, but entity/player
  collision entry is disabled with a notice guiding players to access them via RSW.
- Blood Moons and Super Blood Moons are isolated exclusively to RSW via Enhanced Celestials
  datapack configuration in `config/paxi/datapacks/gangs_fixes/`.
- `/rtp` is restricted to Wild Overworld and RSW Overworld; disabled in Nether and End dimensions.
- GoldClaim updated to 1.0.32: multi-dimension reset orchestration, portal redirection,
  custom Nether generator registration, world border enforcement, and wild portal entry cancellation.
- Client automatic Packwiz updates enabled; personal options, keybindings, and server lists
  remain untouched.

The ZIP contains a separate stopped-server update payload (`server-update/`).
Stop the server, make a world backup, apply `Install-ServerUpdate.ps1`, and restart manually
when ready. The live server was not modified or restarted during release preparation.

Validation:
- GoldClaim test suite passed (35 tests) and build completed (`goldclaim-1.0.32.jar`).
- Packwiz metadata validated and refreshed.
- All-in-one release ZIP built and verified (647 entries).
- Headless auto-update test (`Test-AutoUpdate.ps1`) passed: verified personal settings retention,
  managed config updates, and client-only mod selection.
- Update installer test (`Test-UpdateInstallers.ps1`) passed: verified client and stopped-server
  installers, file preservation, and clean replacement of GoldClaim and legacy mods.
