# The Gangs Modpack v1.1.2

- RSW fire spread disabled on dimension load, after resets and during maintenance.
- Default Options 18.0.6 adds first-run settings/keybindings and the public
  Multiplayer entry `gangs-adventure.playit.plus`.
- Automatic client-only Packwiz updates enabled for new Prism imports.
- Existing players: run the included client-update installer against your
  existing Prism game directory once, then keep that instance and press Play
  for future normal client pack updates. Do not reimport each release.
- Personal options, keybindings, resource-pack selections and saved server lists
  are preserved. Pack-managed mod configs can still receive release changes.
- Update failures block launch and appear in Prism's log; internet access is required.
- Includes the previously prepared Gangs Cosmetics 2.0.2, Soulslike Backpacks
  Compatibility 1.1.0 and GoldClaim hostile-mob claim combat/native trash changes.

The ZIP contains a separate stopped-server update payload. Stop the server,
make a world backup, apply its installer and restart manually when ready.
The live server was not modified or restarted during release preparation.

Validation: 35 GoldClaim tests and 8 compatibility tests passed; builds
completed. Disposable client/server installer tests preserved personal data,
worlds and the RSW journal/config. Two real headless Packwiz updates verified
byte-for-byte preference retention, changing managed defaults, and client-only
mod selection. Default server NBT and packaged mod hashes were verified.

In-game verification on the actual server remains for the scheduled restart.
