# v1.1.12: JourneyMap claim overlay discovery fix

## Existing players

Close Minecraft and press **Play** in your existing Prism instance. Packwiz
replaces GoldClaim Map 1.0.0 with **1.0.1**. No ZIP reimport or server restart
is needed. Personal settings and saved servers are unchanged.

The server continues running GoldClaim 1.0.42. No server files, claims,
worlds or protection rules change.

## Root cause and fix

The client log showed Waystones' bundled JourneyMap plugin referencing the
old `journeymap.client.api.IClientPlugin` interface. This pack's JourneyMap
6.0.0-beta.5 uses API v2 instead. Fabric's bulk entrypoint lookup throws when
loading that legacy plugin, so JourneyMap abandons discovery of every plugin,
including GoldClaim Map.

GoldClaim Map 1.0.1 includes a client-only compatibility mixin at that lookup.
It loads entrypoints individually, logs incompatible entrypoints and continues
with valid ones. JourneyMap still handles plugin filtering, initialization and
overlay rendering normally. This does not repair Waystones' legacy map plugin
or change Waystones itself.

Gold outlines, faint amber fill, owner-name hover labels and full-screen-only
display remain unchanged. Two new diagnostic messages distinguish renderer
initialization from receipt of claim data:

- `JourneyMap claim overlay plugin initialized`
- `Received N claim regions from the server`
