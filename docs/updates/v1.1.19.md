Publishing does not stop, restart, reload or otherwise modify the live server.

## Included fixes

- **Item Borders endless config rewrite.** Item Borders defines
  `manual_borders` as an empty table with a comment. An empty TOML table is
  not written, so the comment is lost. Forge Config API Port then reports the
  file as "not correct" on every check, rewrites it, and its file watcher
  reloads it again, so it writes and logs every second for the whole session.
  The shipped config adds the harmless placeholder `white = []` (no items) so
  the table and its comment persist. The mod may correct it once on first
  launch, then it stays stable. Keep at least one entry in that table.
- **FoxFriend tick log spam.** Upstream 6.0.3 prints a debug line from
  `FoxMixin.onTick` every tick for every fox
  ([upstream issue](https://github.com/sui-ke/Minecraft-Mod-FoxFriend/issues/11)).
  The 9-byte `System.out.println` call was replaced with no-ops; every other
  class and resource is byte-identical to the Modrinth 6.0.3 jar.
- **Alex's Caves Grottoceratops egg model.** The shipped
  `grottoceratops_egg_template.json` ended with `},`, which fails to parse and
  broke the normal, cracked and very cracked egg models. The trailing comma
  was removed in the jar and in `sources/alexscaves-fabric-2.1.8-source.zip`.

## Not changed

- The Supplementaries REI error about sack coloring is an upstream
  Supplementaries/Supplementaries Squared incompatibility. Both are already
  the newest 1.20.1 Fabric releases; only some REI recipe pages are missing.
- Bakery 1.1.15 with Farm & Charm 1.0.14 is unchanged; switching to Bakery
  2.x needs a world backup and migration test first.

## Server

Client and server FoxFriend builds are behaviorally identical except logging.
